Projeto TechSustentável

Em grupo de três integrantes, vocês irão aplicar repositório compartilhado, branches individuais, commits, merge para a main e publicação com GitHub Pages.

← Voltar ao curso

Proposta do projeto

TechSustentável — Ideias Digitais para um Futuro Melhor

O grupo deverá criar um pequeno site sobre como a tecnologia pode contribuir para práticas sustentáveis no cotidiano, na escola, nas empresas e nas cidades.

O objetivo principal é demonstrar o trabalho colaborativo com Git e GitHub. O site deverá funcionar, mas o histórico do repositório, as branches e os commits também fazem parte da atividade.

Formação do grupo

Formem um grupo com três integrantes. Um aluno será responsável por criar o repositório e compartilhar o acesso com os outros dois.

Integrante 1

Desenvolver tecnologia.html, apresentando tecnologias que podem contribuir para sustentabilidade.

Integrante 2

Desenvolver projetos.html, apresentando ideias de projetos sustentáveis apoiados pela tecnologia.

Integrante 3

Desenvolver acoes.html, apresentando ações práticas sustentáveis para pessoas, escolas ou empresas.

1. Criar e compartilhar o repositório

  1. Um integrante cria no GitHub um repositório chamado techsustentavel.
  2. Esse aluno adiciona os outros dois integrantes como colaboradores.
  3. Todos clonam o mesmo repositório em seus computadores.
git clone URL_DO_REPOSITORIO
cd techsustentavel
Atenção: o grupo terá apenas um repositório. Não devem ser criados três repositórios separados.

2. Criar uma branch para cada integrante

Cada aluno deverá criar uma branch utilizando o próprio primeiro nome. Exemplo para um grupo formado por Ana, Bruno e Carlos:

git switch -c ana
git switch -c bruno
git switch -c carlos

Cada integrante executa apenas o comando correspondente à sua branch. Em seguida, confira:

git branch
Antes de editar os arquivos, confirme que o asterisco * está ao lado da sua branch e não da main.

3. Cada integrante desenvolve sua página

IntegranteArquivoRequisitos mínimos
1tecnologia.htmlTítulo, introdução, pelo menos 3 tecnologias e elemento visual.
2projetos.htmlPelo menos 3 ideias de projetos, descrição e benefícios.
3acoes.htmlPelo menos 5 ações práticas e explicação de cada uma.

Cada integrante deve realizar pelo menos dois commits na própria branch.

git status
git add .
git commit -m "Cria estrutura da minha pagina"
git push -u origin NOME_DA_SUA_BRANCH

4. Integrar as três branches na main

Quando as páginas estiverem prontas e enviadas ao GitHub, o grupo deverá fazer o merge de todas elas para a main.

git switch main
git pull

git merge ana
git merge bruno
git merge carlos

git push origin main
Os nomes acima são apenas exemplos. Usem os nomes reais das branches do grupo. Se ocorrer conflito, o grupo deverá analisá-lo e resolvê-lo antes de concluir o merge.

5. Criar a página principal

Depois dos merges, um integrante ficará responsável por criar ou finalizar o arquivo index.html. Ele será a página inicial do projeto.

O index.html deverá:

  • apresentar o nome TechSustentável;
  • explicar a proposta do site;
  • mostrar os nomes dos três integrantes;
  • conter links para tecnologia.html, projetos.html e acoes.html;
  • possuir organização visual coerente com o restante do site.
<nav>
  <a href="tecnologia.html">Tecnologia</a>
  <a href="projetos.html">Projetos</a>
  <a href="acoes.html">Ações Sustentáveis</a>
</nav>

6. Publicar com GitHub Pages

  1. Confiram se os arquivos finais estão na branch main.
  2. Abram as configurações do repositório.
  3. Acessem a opção de publicação do GitHub Pages.
  4. Configurem a publicação utilizando a branch main.
  5. Após a publicação, abram o endereço público e testem todos os links.
Entrega:

Ao término, apenas um integrante do grupo deverá enviar na atividade o link público gerado pelo GitHub Pages.

Os outros integrantes não precisam enviar o mesmo link. O professor poderá verificar no repositório as branches, os commits e a participação de cada componente.
